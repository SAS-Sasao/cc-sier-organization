## 本組織への影響

`wf-daily-digest` の巡回 8 ソースを信頼ドメイン群と照合したところ、**8/8 が信頼ドメイン外**だった。
AWS 系も `aws.amazon.com` であって `docs.aws.amazon.com` ではないため対象外。

つまりダイジェストは二重要約（原文 → 中間 LLM が数百字 → Opus が章立て・1文要約）になっている。

L2 レビューは生成された MD を評価対象とするため、**原文に対する忠実性は構造的に検証できない**。
composite 0.98 はこの経路の健全性を意味しない。
