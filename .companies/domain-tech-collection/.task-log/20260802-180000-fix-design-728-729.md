## 判断 1: Issue #728 — 衝突検出が発火せず値が silent loss する

### 問題

§4.3.5 の intra-title 衝突検出は `ファミレス／6月既存店すかいらーく1.7％増、サイゼリヤ9.7％増` で
衝突する前提だったが、§4.3.1 の左窓規則では 2 件目の左窓が `サイゼリヤ` になり指標が解決できない。
observation が 1 件しか生成されないため**衝突検出が構造的に発火しない**。

結果、1 行で 2 つの事故が同時に発生していた（実測 16 行）。

1. 個社の値（すかいらーく 1 社の実績）が業態の観測値として記録される
2. もう一方の値が observation にも `unresolved` にも現れない（**silent loss**、FR-10 違反）

### 確定した判断

**案 1（`out_of_scope` に落とす）を基本に採用。ただし一律ではなく判定条件を精緻化した。**

却下した案:
- **案 3（左窓を広げて衝突させる）** — 個社の値を業態に 2 件記録してから片方を潰す形になる。
  カタログ §1.4 が「個社決算は `out_of_scope` 分類とする」と明記しており、そもそも記録すべきでない
- **案 2（LLM に回す）** — 正解が `out_of_scope` である以上、決定論的に判定できる。
  LLM は非決定性とコストを持ち込むだけで精度は上がらない

**16 行を一律 `out_of_scope` にするのは誤り**だった。2 種類が混在している。

| 種類 | 例 | 1 件目の扱い |
|---|---|---|
| (a) 個社の並記 | `ドラッグストア／2月既存店売上ツルハ4.0%増、コスモス薬品7.0%増` | `out_of_scope` |
| (b) 業態内の内訳 | `家電大型専門店／4月の販売額は12.1％増、生活家電が15.8％増に（経産省調べ）` | **正当な観測値** |

(b) はカタログ §1.1 が `electronics-retailer` の発表主体を経産省のみとしている業態統計そのもので、
落とすと本来取るべきデータを捨てることになる。

**判定基準**: 値の左窓に残る「未解決の残余語」が期間表現か不明語か。
`ツルハ` は不明語 → (a)、`4月の` は期間表現のみ → (b)。
§4.3.3 の主語位置ガードの自然な拡張（あちらは主語の位置、こちらは値の直前の修飾語で弾く）。

**FR-10 は無条件の絶対条件**として明記した。値トークンが observation にも `unresolved` にも
現れない状態は、NFR-05 の分子が減ることや実装の複雑さを理由に許容しない。

`reason_code` に `company_disclosure` / `no_metric_match_in_multi_value` を追加。

## 判断 2: Issue #729 — 素の「売上高」が率側に解決できない

### 問題

カタログ §2.2 が「単に『売上高』であれば絶対額か率かでさらに分岐」と定めているのに、
**V12（別名が指標内で重複しない）がその表現を禁じていた**。§2.2 と V12 が両立していない。

さらに実装側が値の型フィルタを入れる前は、**`3.2`（%）が単位 `jpy_oku` の指標に格納されていた**
（率を億円として蓄積）。例外にならないため golden-60 が無ければ気づけなかった。

### 確定した判断

**案 2（V12 の緩和）を採用。**

```
V12（改訂後）: 別名が指標内で重複しない。
               ただし 値種別（ratio / absolute）が異なる指標間では同一別名を許す。
               値種別が同一の指標間では引き続き禁止する。
```

決め手は**曖昧性が記事側に実在する**こと。`売上高3.2％増`（率）と `売上高1兆4505億円`（絶対額）は
同じ語で両方を指しており、記事表記の性質であってカタログの設計不備ではない。

後半の禁止（値種別が同一なら不可）を維持することが要点。緩めると型で絞っても一意に決まらず、
「どの ID に寄せるか」が結局コード側の暗黙ルールになり NFR-09 が崩れる。

却下した案:
- **案 1（率側に別表記を足す）** — 記事の実表記が素の `売上高` である以上マッチせず、1 行も解決しない
- **案 3（現状維持）** — 落ちる 3 行のうち 2 行が日本百貨店協会の月次統計そのもので、
  本システムが最も取りたいデータ
