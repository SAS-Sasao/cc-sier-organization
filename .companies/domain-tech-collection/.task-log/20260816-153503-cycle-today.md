#### 検出した構造欠陥 — PR #787 では直らない

本 task-log は **PR #787 の新テンプレートに従い `## reward` 見出しを書かなかった**。それでも evaluator は `score: 0.2` を付けた。

```yaml

signals:
    completed: false      # ← Phase 1.5 時点では in-progress
    artifacts_exist: false
```

**原因は `/company-cycle` のフェーズ順序にある。**

```
Phase 1.5  evolve → evaluate_session を実行   ← ここで自分の task-log を評価
Phase 3    task-log を completed にする       ← 評価はもう終わっている
```

cycle は**自分自身の task-log を in-progress のまま評価する**構造になっており、べき等ゆえに完了後も直らない。**テンプレート修正（#787）はこの経路を解決しない。**
