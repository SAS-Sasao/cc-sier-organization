## C. クロスドメイン分析

### 1. Lambda Web Functions と小売EC基盤の次世代アーキテクチャ

AWS Lambda Web Functionsの正式発表は、サーバーレスでHTTPリクエストを直接処理できる新パラダイムを開いた。DevelopersIOではマルチリージョン構成、Cold Start計測、Bedrock統合などの検証記事が一斉に公開されている。小売EC側では日本のEC市場が2034年に111兆円規模へ拡大する予測が出ており、BASE・セカンドストリートなどのプラットフォームがAI機能を急速に強化している。SIerとしては、Lambda Web FunctionsをEC基盤のBFF（Backend for Frontend）として採用し、AIエージェントとの統合によるパーソナライズド・ショッピング体験の構築提案が差別化ポイントになりうる。

### 2. 大規模情報漏えいの連鎖とアプリセキュリティの緊急課題

ソースネクスト2,252万件・バーガーキング1,118万件と大規模情報漏えいが同時多発している。JPCERT/CCは「A2B攻撃」（アプリ解析→API脆弱性突破）を新たな攻撃パターンとして報告し、ラックも国内Webシステムの情報漏えいトレンド変化を分析している。小売EC事業者にとってアプリセキュリティは喫緊の課題であり、IPAも緊急の点検・対策を事業者に要請している。SIerの立場では、API Gateway + WAF + Bedrock AgentCoreの組み合わせによるセキュリティ監視基盤の提案や、クレカ番号非保持設計の徹底支援が急務となる。

### 3. AI発注・AIエージェントが小売業の収益格差を拡大

ローソンがAI発注で平均日販60.8万円の過去最高を記録する一方、リテールパートナーズは人件費増で営業利益17.2%減と、AI活用の有無が収益に直結する構図が鮮明になっている。技術側では富士通が小売業向けAIエージェント基盤の試用提供を開始し、GapはAIスタイリングで次世代ショッピング体験を推進。大丸松坂屋百貨店も接客データ×AIの新サービスを開始した。SIerとしては、AIエージェントの導入効果を発注精度・日販向上の定量KPIで示す提案と、接客データ×AIの統合基盤構築が重要な案件機会となる。

### 4. アパレル経営統合とシステム統合SIer案件の創出

ワールドとTSIホールディングスが2027年3月に持株会社「インフィニティ・ユナイテッド」を設立する経営統合は、システム・物流・データ活用のシナジーを狙ったものと報道されている。イズミも九州スーパー3社統合を進めており、U.S.M.Hは約100店舗閉鎖の大規模再建に着手した。これらの統合・再編案件は、基幹系システム統合・データ基盤統合・物流システム再構築など、SIerにとって大型案件の創出機会となる。Snowflakeの権限委任機能やdbt+PrivateLinkの接続構成など、データ基盤統合の技術的な選択肢も充実してきている。
