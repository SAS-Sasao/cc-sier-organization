## C. クロスドメイン分析

### 1. 小売業界へのサイバー攻撃連鎖と、技術側の対応策のギャップ

11月に入りニトリ（3,762万件）、良品計画（2,726万件）、ビックカメラ（1,520万件）、アイリスプラザ（770万件）、ロート製薬（280万件）、エディオンと、主要小売・消費財企業への大規模不正アクセスが連鎖的に発生した。特に無印良品では「クレカ番号を暗号化せず保持」という根本的な脆弱性が露呈している。一方、技術側ではAWS Security HubのSBOMインベントリ提供開始、OWASP ASVS L1の要件定義段階での導入提案、CRA対応の自動化など対策ツールの整備は進んでいる。SIerとしては、小売業クライアントに対して「PCI DSS準拠の棚卸し」と「SBOM管理の導入」をセットで提案する好機であり、セキュリティ診断の初回無償化などで案件獲得につなげる戦略が有効である。

### 2. AWS Emulatorのローカル開発革新と、小売システムの開発生産性向上

AWS Emulatorの検証記事が複数ソースで同時にトレンド入りし、CDK/Terraform対応、CloudFront+API Gateway+Cognito構成のローカル実行が実用レベルに達していることが確認された。小売業界では、ライフのアルビス子会社化やPPIHのOlympic統合など、M&Aに伴うシステム統合案件が増加しており、統合時のPoC・テストにAWS Emulatorを活用することで、本番環境を汚さずに統合検証が可能になる。認証（Cognito）やCDN（CloudFront）を含む構成がローカルで動作する点は、店舗系Webアプリの開発サイクル短縮に直結する。

### 3. AIエージェント技術の成熟と、小売EC・業務プロセスへの浸透

技術側ではClaude Code活用の知見が急速に蓄積されている。「Skills付き単一エージェントがマルチエージェント構成より品質で上回る」というAnthropicの公式知見、SessionStart hookの上限（1万字）の実測、トークン最適化（4割減）など、実務に直結する発見が多い。小売側ではLINEヤフーの「Agent i」アプリ提供開始、八代目儀兵衛のGEO（生成エンジン最適化）でAI流入4.5倍達成、Google Universal Cartによる複数EC一括購入など、消費者接点にAIエージェントが急速に浸透している。SIerとしてはClaude Code等のAIコーディングツールで開発生産性を上げつつ、クライアントにはGEO対策やAIエージェント対応のEC改修を提案する二正面戦略が求められる。

### 4. 小売M&A・業態転換ラッシュと、SIシステム統合需要の拡大

ライフによるアルビスの228億円子会社化、PPIHのOlympic業態転換1号店（MEGAドン・キホーテ）、すかいらーくのShinShin買収（120億円）など、小売業界のM&A・業態転換が加速している。これらの統合にはPOS・基幹システム・EC基盤の統合が必須で、SIer向けの大型案件が発生する。イトーヨーカドーの大規模改装計画（26年度46店舗、27年度70店舗）も同様に、店舗システムの更新需要を伴う。決算好調企業（ニトリHD増収増益、三越伊勢丹HD上方修正、マツキヨココカラ増益）はIT投資余力があり、提案のタイミングとして最適である。

### 5. AIファーストBI（Snowflake Dashboards 2.0）と、小売データ活用の深化

Snowflake Dashboards 2.0がZenn・DevelopersIOで同時に検証記事として公開され、AIファーストBIが実用段階に到達した。小売業界ではダイヤモンド・チェーンストアの「AI時代のSC経営データ活用は顧客理解で終わっていないか」というコラムが示すように、データ活用の深化が課題となっている。dbt+SnowflakeでのSurrogate Key vs Durable Keyの実践検証、AWS GlueのIceberg RESTカタログフェデレーション対応なども合わせると、小売業向けデータ基盤の提案にAIファーストBIを組み込むことで、単なるDWH構築から「経営意思決定支援」へ提案の付加価値を高められる。
