## C. クロスドメイン分析

### 1. 小売業セキュリティ危機とAIセキュリティ技術の交差

小売業界では無印良品（クレカ情報109万件）、モスバーガー（751万件）、ライフ（13万件）と大規模情報流出が同時多発している。一方で技術側ではOpenAIの「GPT-6 Cyber」がFirefoxの未知の脆弱性81件を自動検出し、AWSも「Continuum Code Vulnerabilities」やWAF SDK自動統合、Auroraのポスト量子TLSなどセキュリティ機能を次々にリリースしている。SIerとしては、小売業のEC基盤・会員基盤に対してAI脆弱性診断の導入提案や、全自動ペネトレーションテスト環境の構築が差別化ポイントになる。ECサイト運営者の約3割が「不正の原因・手口を特定できていない」という調査結果からも、AI活用による脅威可視化のニーズは高い。

### 2. AIエージェントコマースの実装フェーズへの移行

WalmartがAnthropicのMCP規格を採用してAIエージェントコマースを推進する動きは、小売×AIの実装が構想から実運用に移行していることを示す。技術側ではAIエージェントの品質担保（定理証明ガードレール、自作lintによる規約強制）やDevOps Agentの本格活用が進み、エージェント開発の成熟度が上がっている。国内でもシノプスの需要予測×自動納品やJDSCのAI配送再計画が食品スーパーや物流で実証段階に入っており、SIer案件としてエージェント基盤の構築・運用支援が具体化しつつある。

### 3. 家電量販店のPC販売急落が示すAI時代の消費構造変化

ケーズデンキ（PC -62.9%）、エディオン（PC -60.2%）と家電量販店のパソコン販売が6割減という異常値を記録した。AIアシスタントの普及やスマートフォンの高機能化が個人のPC需要を浸食している可能性がある一方、Claude Codeを使ったISUCON参戦やAI駆動開発ではPC/開発環境の需要が法人向けに移行しているとも読める。SIerとしてはB2B向けのAI対応端末・開発環境提案と、小売業向けPOSシステムのクラウド化（PC不要化）という二軸で提案機会がある。

### 4. データレイクハウスの標準化進行と小売業のデータ活用

Apache Iceberg関連でS3 TablesのHive→Iceberg移行、Glueカタログの最適化対応、AWS Redshiftの自動クロスリージョンバックアップなど、データ基盤のマネージド化が急速に進んでいる。Snowflake CoCo for Excelは業務ユーザーが自然言語でデータ分析できるインターフェースを提供する。小売業のPOS・EC・物流データを統合分析するDWH構築案件では、Icebergベースのレイクハウス+自然言語分析の組み合わせが実践的な提案構成となる。
