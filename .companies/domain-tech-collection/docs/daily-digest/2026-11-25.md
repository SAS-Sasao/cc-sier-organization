## C. クロスドメイン分析

### 1. AIエージェント基盤の成熟と小売コマースへの波及

技術側では Anthropic が Claude Ship（コード承認AI）とMCPサーバーからの Skill 配布機能を発表し、AIエージェント基盤が急速に成熟している。AIハーネスは第3世代の自己改善型へ進化し、Copilot Studio や Agentforce 等のプラットフォームとの MCP 連携も進む。小売側ではエージェンティック・コマース市場が12.5兆円規模と試算され、楽天トラベルのAIエージェント型レンタカー提案など実装が加速している。SIerとしては、MCP準拠のエージェント統合基盤を小売企業の購買体験・カスタマーサポートに組み込む提案が差別化ポイントとなる。エージェント型決済と顔認証決済の連携も新たな提案領域となりうる。

### 2. 大規模情報漏洩とECセキュリティの危機

楽天証券の441万件情報漏洩（うち口座未開設者119万件含む）が技術セキュリティの面で大きな衝撃を与えている。同日にはJAXAへの不正アクセスも報じられ、11月のサイバー事故は605件に達したとの分析もある。小売側ではECサイトへの不正アクセスによるカード情報漏洩が2事案報告され、消費者の約半数が「情報漏洩を知り新規会員登録に慎重になった」とする調査結果が出た。SIerが小売・EC企業に提案する際は、テスト環境でのデータマスキング導入、Ghostscript等の画像処理脆弱性対策、AWS WAF Security analytics ダッシュボードを活用した横断的脅威可視化が具体的な提案テーマとなる。

### 3. 形式検証・品質保証とAI時代のソフトウェアエンジニアリング

Lean 4による著名Rust OSSの形式検証で多数のバグが発見された報告は、テスト自動化だけでは見つからない品質問題の存在を示している。37signalsの独自品質戦略や「コードを書くコストが下がった今のSEの価値」の議論と合わせると、AI時代の差別化はコーディングから設計・検証・品質保証にシフトしている。小売システムの信頼性確保（POS・決済・在庫管理）にも形式検証手法を適用する可能性があり、SIerにとっては品質保証サービスの高度化が競争力の源泉となる。

### 4. 小売店舗戦略の多様化とデジタル融合

トライアル西友の23区初出店（総菜新ブランド・スムージー等の新MD投入）、薬王堂の千葉初進出、ユニクロの個店経営戦略、サミットの「楽しいスーパー」構想と、小売各社の店舗戦略が多様化している。同時にイオンリテールのシニア向けEC、ローソン×日本郵便の郵便局EC、日立の顔認証決済など、実店舗とデジタルの融合が進む。SIerとしては、新規出店に伴うシステム構築需要を捉えつつ、シニア層・地方拠点向けのオムニチャネル基盤の提案が求められる。クラウド側ではAWS CDK BlocksのGA化やExtendDB v1.0等、基盤構築の選択肢が広がっており、コスト最適な構成提案の幅も増えている。
