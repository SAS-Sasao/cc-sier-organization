## C. クロスドメイン分析

### 1. AIエージェントがEC・物流のオペレーションを変革する

楽天が「スーパーエージェント」構想を打ち出し、花王はAIエージェント「Kao-MIKOMIL」で需要予測を実用化、ディナレッジはAIでトラック配車を自動化——技術側のAIエージェント基盤整備（AWS AgentCore、Claude Code Skills/Plugins）と、小売・物流側のエージェント活用が急速に収斂している。SIerとしては、エージェント基盤の構築と業務プロセスへの組み込みを一貫して提案できる体制が差別化ポイントになる。特にAWS DevOps Agentのマネージドスキルや、AgentCoreのHarness機能で人間承認を挟む設計パターンは、小売業務フローへのエージェント導入時の安全策として直接応用可能である。

### 2. オープンウェイトLLMの台頭と小売AI活用のコスト構造変化

Qwen3.8-27BやGLM-5.3などオープンウェイトモデルが相次いで公開され、ローカル推論環境の整備も進んでいる（WSL2+Ollama+RTX 5070 Ti）。一方、StripeによるOpenRouter買収交渉は、AI推論のルーティング・課金インフラが次の投資対象であることを示す。小売企業がAI需要予測や商品推薦を内製化する際、オープンウェイトモデル＋クラウド推論の組み合わせがコスト面で有力な選択肢となり、SIerにはLLMルーター設計（Nemotron LoRAファインチューニング等）を含む技術選定と運用設計の支援が求められる。
